## Value Proposition & Features

TrustedRouter is a hosted, OpenAI-compatible AI gateway offering one API key and endpoint for more than 600 models from over 100 providers, with automatic provider failover. [^m3ycz4] Its differentiator is a privacy- and trust-oriented gateway architecture: attested infrastructure, no prompt or output logging, EU routing, zero-data-retention routes, and support for customer provider keys. [^m3ycz4]

- **Unified model access:** One endpoint and model identifier provide access to hundreds of models across many providers. [^m3ycz4]
- **Automatic failover:** Requests can use multiple provider routes so an outage or unavailable route does not necessarily interrupt service. [^m3ycz4]
- **Attested infrastructure:** The gateway can attest to the exact software build running on its confidential hardware. [^m3ycz4]
- **No prompt/output logs:** TrustedRouter states that it does not log prompts or outputs. [^m3ycz4]
- **EU gateway:** EU traffic can remain in Europe for authentication, policy checks, provider selection, and streaming initiation. [^m3ycz4]
- **Zero-data-retention routes:** Model listings identify providers and routes that offer zero data retention. [^mz9bk4][^7l5zmz]
- **[[concepts/Bring Your Own Keys|BYOK]]:** Customers can use their own provider keys. [^m3ycz4]
- **Combo models:** Prometheus, Liberty, and Polyphemus combine or route across multiple models behind a single model ID. [^flp3s6]

## Competitive Landscape

### Who it's for, who it's not for

TrustedRouter is aimed at teams that want OpenAI-compatible access to many models while emphasizing provider redundancy, attested infrastructure, regional routing, zero-data-retention options, or customer-managed provider keys. [^m3ycz4][^flp3s6] It is also relevant to agent builders that need one stable model interface while routing or combining requests across multiple underlying models. [^flp3s6][^mhi0u5]

It is less suitable for users seeking a single-model API, a fully self-hosted gateway, or a provider with publicly documented revenue, team, and enterprise operating history; the available sources do not establish those details for TrustedRouter.

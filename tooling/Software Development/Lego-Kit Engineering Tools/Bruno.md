## Value Proposition & Features

Bruno is a local-first, open-source, Git-friendly API client for developers. It is designed to keep API collections alongside source code rather than relying on cloud-synced workspaces. [^wyp7c1] Its manifesto emphasizes co-located, version-controlled collections and avoiding proprietary collaboration systems and cloud exposure. [^z7j3rj]

- Supports [[Vocabulary/REST API|REST API]], [[projects/Emergent-Innovation/Standards/GraphQL|GraphQL]], SOAP, [[Tooling/Software Development/Developer Experience/DevOps/gRPC|gRPC]], and [[Vocabulary/WebSockets|WebSocket]] requests. [^v7ywf0]
- Stores collections in Git-friendly repositories for collaboration and version control. [^wyp7c1] [^z7j3rj]
- Provides request configuration for parameters, headers, bodies, authorization, and multiple HTTP methods. [^scpr37]
- Includes scripting utilities and support for custom [[projects/Emergent-Innovation/Standards/Transport Layer Security|TLS]], proxy, and client-certificate settings. [^j1et3y]
- Offers a CLI for running collections in automation and CI/CD pipelines. [^emcw43] [^044e6h]
- Generates JSON, JUnit, and HTML test reports from CLI runs. [^044e6h]
- Imports OpenAPI and WSDL specifications into runnable collections. [^044e6h]
- Generates standalone HTML API documentation with an embedded playground. [^044e6h] [^zrbf1p]

# Competitive Landscape

## Who it's for, who it's not for

Bruno is suited to developers and engineering teams that want API requests, examples, tests, and documentation stored beside application code, with Git-based workflows and optional CLI automation. [^wyp7c1] [^emcw43] [^z7j3rj] It is also suited to teams testing [[Vocabulary/REST API|REST API]], [[projects/Emergent-Innovation/Standards/GraphQL|GraphQL]], [[SOAP]], [[Tooling/Software Development/Developer Experience/DevOps/gRPC|gRPC]], or [[Vocabulary/WebSockets|WebSocket]] services. [^v7ywf0]

It is less suited to teams that require a fully cloud-native workspace as their primary collaboration model, because Bruno’s positioning centers on local execution and repository-based collections. [^wyp7c1] [^z7j3rj]

## Viable Alternatives

- **[[Tooling/Software Development/Developer Experience/DevOps/Postman|Postman]]** — A conventional API client and collaboration platform; Bruno’s manifesto positions its Git-native, local-first model as an alternative to proprietary cloud workspaces. [^z7j3rj]
- **[[Insomnia]]** — An API design and testing client that can serve teams seeking an alternative desktop API workflow.
- **[[Tooling/Software Development/Developer Experience/DevTools/Hoppscotch]]** — A browser-oriented API client for users who prioritize web accessibility.
- **[[curl]]** — A command-line HTTP tool for lightweight request execution and scripting, though it lacks Bruno’s graphical collection and documentation workflow.
- **[[HTTPie]]** — A developer-oriented command-line API client for terminal-based request workflows.

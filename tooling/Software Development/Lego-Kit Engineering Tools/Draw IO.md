## Value Proposition & Features

Draw IO—officially **diagrams.net**—is a free graph-drawing application for creating and exporting technical and business diagrams, including flowcharts, UML diagrams, mind maps, floor plans, circuit diagrams, and infographics. It is available as a browser application or standalone desktop program and does not require online registration. [^E1]

Its central proposition is deployment and storage flexibility: users can work in the web editor, desktop application, or connected document platforms, while diagrams remain ordinary files in the selected storage environment. The official SharePoint integration states that files remain in the customer’s libraries and that draw.io servers do not store diagram content. [1]

Priority features:

- Browser-based diagram editor. [^E1]
- Standalone desktop application. [^E1]
- Export of multiple diagram types and formats. [^E1]
- Flowcharts, [[projects/Emergent-Innovation/Examples/Unified Modeling Language|UML]], mind maps, floor plans, circuit diagrams, and [[Vocabulary/Infographics|Infographics]]. [^E1]
- [[Tooling/Products/SharePoint|SharePoint]] integration with inline viewing and editing. [1]
- Concurrent editing and automatic saving in SharePoint. [1]
- Custom links, multi-page navigation, presentation mode, and page animations. [2]
- Gliffy-to-draw.io migration tooling with dry-run testing and conversion reports. [3]

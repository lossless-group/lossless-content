## Viable Alternatives

- **LibreOffice** — broader office-suite functionality with document import and export.
- **Quarto** — publishing-oriented workflows built around computational and technical documents.
- **Sphinx** — documentation generation, particularly for software projects.
- **Jupyter nbconvert** — conversion of computational notebooks into other formats.
- **AbiWord** — lightweight word-processing and document-conversion functionality.
